# Watercolor art

Every painting on the business site is generated by `scripts/watercolor/` and committed as WebP in `public/img/paint`. Nothing is drawn by hand or stock: the same seed always paints the same picture.

```sh
pip install -r scripts/watercolor/requirements.txt
npm run generate:paintings              # everything
python3 scripts/watercolor/generate.py hero work-radio   # just some
npm run generate:brand-images           # social cards reuse the paintings
```

## Art direction

"Wet ink, hard pixel": loose, transparent watercolor (the hand) meeting precise ink geometry and flat pixel grids (the code). The studio mark, two overlapping rings, is painted in cerulean and rose; where they overlap the glaze turns violet. Most paintings carry one digital element: a region resolved into palette-snapped pixels, or measured ink linework over the paint.

## How the renderer works (`engine.py`)

- **Washes** follow Tyler Hobbs' method: a polygon is deformed by recursive midpoint displacement, then dozens of further-deformed copies are stacked at low opacity, each masked by blotchy noise.
- **Pigment** is glazed with Beer–Lambert absorption in linear light, so overlapping colors mix like transparent paint.
- **Finishing** adds a wet-on-dry body, darker dried edges, low-frequency flow, blooms, and granulation from a periodic paper height field.
- **Pixel dissolve** snaps cells to the painting's own k-means palette and reveals them through an ordered-dither threshold, with optional breakaway cells.

## Assets

| File | Where |
| --- | --- |
| `hero-fusion.webp` | Home hero (the construction overlay in `explore.astro` uses viewBox `80 200 1240 1000`) |
| `fusion-mark.webp` | Welcome screen, default social card |
| `work-<slug>.webp` | Project cards and case-study headers (`art` in `src/data/projects.ts`) |
| `service-*.webp` | Service cards and the services page |
| `step-1..3.webp` | Process markers |
| `swatch-*.webp` | Highlighter strokes behind `.hand` words (RGBA) |
| `cta-wash.webp`, `cta-wash-tall.webp` | Closing call to action (wide and phone) |
| `portrait-matthew.webp` | Founder photo with the background repainted from its own colors |
| `paper.webp` | Seamless page texture, shown at half size |

Paintings are rendered on white and shown with `mix-blend-mode: multiply`, so they glaze onto the page paper. Don't put `transform`, `opacity`, `filter`, or `isolation` on an ancestor of a `.paint` image.

To add a case study, give it a painting function in `generate.py` (see `work_edd` for a compact example), register it in `ASSETS`, and point the project's `art` at the new file.
